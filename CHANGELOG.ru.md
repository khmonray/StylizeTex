# Changelog

## 0.0.1 — Немедленное применение к материалу и необязательная упаковка

### Реализовано

- Добавлен `Apply to Material`, включённый по умолчанию (`True`). После успешного запуска созданное изображение сразу подключается через один помеченный узел Image Texture ко входу `Base Color` Principled BSDF активного материала.
- Добавлен `Pack into .blend`, выключенный по умолчанию (`False`). Упаковка необязательна и выполняется дополнительно к записи внешнего PNG; она никогда не заменяет внешний вывод.
- Сохраняются исходное изображение и исходный узел Image Texture. Перенаправляется только прямая связь `Base Color`; несвязанные узлы и связи сохраняются.
- Повторная обработка использует один помеченный созданный узел и один слот результата, читает исходный источник вместо предыдущего созданного результата и удаляет устаревшее созданное изображение, если оно не используется.
- При отключении `Apply to Material` материал сохраняется без изменений, но созданные блоки данных Blender и внешний PNG всё равно создаются.
- Упаковка работает для несохранённого `.blend`, но оператор не сохраняет файл автоматически. Пользователь должен вручную сохранить `.blend`, чтобы сохранить упакованные данные и связь материала; статус сообщает об этом напоминании.
- Внешний PNG записывается всегда, в том числе при включённой упаковке. Явный путь имеет приоритет; иначе используются `Output Folder`, папка исходного изображения, папка `.blend`, а затем временная папка Blender. Некорректные пути и отсутствие прав записи сообщаются как ошибки.
- Документировано ограничение прямой связи Image Texture → Principled BSDF `Base Color`; косвенные shader networks не обрабатываются.
- `Randomize Style` по-прежнему изменяет только поля стиля и seed; флаги поведения `Apply to Material` и `Pack into .blend` сохраняются.

### Проверка

Headless Blender-тесты проверяют значения флагов по умолчанию, немедленное применение, поведение при отключённом применении, сохранность исходных и несвязанных узлов, повторное использование при повторном запуске, внешний PNG при упаковке, упаковку несохранённого blend, откат при ошибках и сохранение флагов поведения при рандомизации.

### Phase 2 и Randomize Style

### Реализовано

- Добавлены настройки Phase 2: `Hue Variation`, `Brush Scale`, `Paint Variation` и `Micro Detail`.
- Добавлены нейтральные значения Phase 2 (`hue_variation=0.0`, `paint_variation=0.0`, `micro_detail=1.0`), побитово сохраняющие результат Phase 1.
- Добавлен точный порядок обработки Phase 2: перевод scene-linear в sRGB, сглаживание micro-detail, упрощение цвета, вариация оттенка, painterly-вариация, низкочастотная вариация, контраст, насыщенность и обратный перевод sRGB в scene-linear.
- Добавлены детерминированные потоки эффектов Phase 2, получаемые из общего `Seed`; alpha остаётся неизменной.
- Добавлены оператор и кнопка `Randomize Style`. Они выбирают новый seed, получают ограниченные диапазоны стиля, изменяют только whitelist стиля, сохраняют resolution/output folder/последний путь результата и не выполняют обработку или файловый ввод-вывод.
- Интерфейс сгруппирован по разделам Source, Output, Color, Large Scale, Painterly и Seed; добавлены действия Process Texture, Randomize Style и Reset.
- Добавлены чистые Python-тесты Phase 2 и randomizer, покрытие оператора в Blender и тестовые визуальные A/B/C-артефакты.
- Обновлена документация упаковки/тестов; сохранён вывод legacy и extension ZIP.

### Не реализовано

- Функции материалов Phase 3: roughness, AO, curvature и генерация материала.
- Функции UX Phase 4: preview, пресеты и пакетная обработка.
- Маски, обработка с учётом геометрии и экспорт GLB.
- Этот релиз не делает утверждений о визуальном качестве.

### Совместимость и проверка

Тестовой целью репозитория является **Blender 5.2.1**. `bl_info` и `blender_manifest.toml` объявляют минимум **4.2.0**. Версии вне проверенной цели не верифицированы.

Чистые тесты запускаются командой `python -m unittest discover -s tests -p "test_*.py" -v`; общий runner — `python scripts/run_tests.py`. Упаковка выполняется командой `python scripts/package.py`. Результаты — `build/stylizetex-legacy.zip` и `build/stylizetex-extension.zip`; тестовые изображения находятся в `build/artifacts/`.

### Phase 1

### Реализовано

- Добавлена боковая панель `StylizeTex` в View3D.
- Добавлена валидация Object Mode, активного меша, активной UV-карты, активного материала, активного выхода Principled BSDF и прямой связи Image Texture со входом Base Color.
- Добавлен конвейер Phase 1: упрощение цвета, плавная низкочастотная вариация, контраст и насыщенность.
- Добавлено преобразование scene-linear/sRGB с сохранением alpha без изменений.
- Добавлено билинейное изменение размера: запрошенное разрешение задаёт длину большей стороны, соотношение сторон сохраняется.
- Добавлены значения настроек по умолчанию, ограничение диапазонов, нормализация разрешения, детерминированный seed и терпимая синхронизация частичных настроек.
- Добавлены создание нового блока данных изображения Blender и вывод PNG без изменения исходного изображения, несвязанных узлов и связей материала.
- Добавлено вычисление fallback для папки вывода и очищенные имена `<object>_stylizetex_basecolor.png`.
- Добавлен оператор сброса настроек.
- Добавлена упаковка классического legacy ZIP и Blender extension ZIP.
- Регистрация сделана безопасной, когда загрузка Blender extension удаляет `bl_info`.
- Добавлены чистые NumPy-тесты и headless Blender-тесты регистрации, обработки, неизменности данных, загрузки namespace и путей установки.

### Примечание о совместимости

Тестовой целью репозитория является Blender 5.2.1. Текущие метаданные объявляют минимум Blender 4.2.0; версии вне проверенной цели не верифицированы.
